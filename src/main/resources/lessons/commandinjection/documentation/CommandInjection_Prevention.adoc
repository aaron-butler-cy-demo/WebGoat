== Prevention

=== Rule 1: Avoid OS commands entirely

The best fix is to replace the shell command with a native library call. Most operations
that rely on system utilities have a Java equivalent:

[cols="1,1", options="header"]
|===
|Avoid |Prefer

|`ping -c 1 ` + host (shell)
|`InetAddress.getByName(host).isReachable(timeout)` (Java)

|`nslookup ` + host (shell)
|`InetAddress.getAllByName(host)` (Java)

|`ls ` + dir (shell)
|`Files.list(Path.of(dir))` (Java)
|===

=== Rule 2: Never pass user input to a shell interpreter

If you must call an external process, use `ProcessBuilder` with each argument as a
*separate list element*. The OS passes the arguments verbatim; no shell is involved and
no metacharacters are interpreted.

[source,java]
----
// UNSAFE — passes input through sh -c, metacharacters are interpreted
new ProcessBuilder("sh", "-c", "ping -c 1 " + ipAddress).start();

// SAFE — no shell; semicolons and pipes in ipAddress are treated as literals
new ProcessBuilder("ping", "-c", "1", ipAddress).start();
----

=== Rule 3: Validate input against a strict allowlist

Before using any value in a system call, reject anything that does not match the smallest
possible pattern for valid input:

[source,java]
----
// Only allow standard IPv4 addresses
if (!ipAddress.matches("^(?:[0-9]{1,3}\\.){3}[0-9]{1,3}$")) {
    throw new IllegalArgumentException("Invalid IP address");
}
----

=== Rule 4: Apply the principle of least privilege

Run the application under an OS account with the minimum rights it needs. If injection
does occur, an unprivileged account cannot read `/etc/shadow`, install software, or
access other users' data.

=== Summary

[cols="1,1", options="header"]
|===
|Dangerous pattern |Safe alternative

|`sh -c "cmd " + userInput`
|`new ProcessBuilder("cmd", userInput)` + input validation

|Denylist filtering (strip `;`, `&`)
|Allowlist validation (reject anything that is not a valid IP / hostname)

|Running as root / SYSTEM
|Dedicated low-privilege service account
|===
